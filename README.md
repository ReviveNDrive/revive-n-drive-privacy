# Revive ’N Drive Privacy Policy

This repository hosts the public privacy policy for **Revive ’N Drive: My Garage** (`com.revivendrive`).

- [Read the privacy policy](PRIVACY_POLICY.md)
- The GitHub Pages version is served from `index.html`.

Revive ’N Drive is the consumer automotive app for understanding, diagnosing, maintaining, repairing, and documenting a user’s own vehicles. It is separate from Mobile Mechanic Shop OS.
